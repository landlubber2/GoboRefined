GoboRefined manual

GoboRefined is an unofficial, modernized spin of GoboLinux 017.01. This page is on your computer and works without internet.

The desktop

  • Start button (the dots on the taskbar, or a short tap on the Win key): search, terminal, Settings, programs by category, Power. Its last entry, Frequently used apps, opens a panel on the left with your pinned items and the programs you start most; it stays until you choose Hide frequently used apps. Right click a program in the menu or the search to Pin to start; in the file manager right click a file or folder
  • Start button (the dots on the taskbar, or a short tap on the Win key): search, terminal, Settings, programs by category, Power.
    • gt; Pin to start; right click a pinned item
  • Start button (the dots on the taskbar, or a short tap on the Win key): search, terminal, Settings, programs by category, Power.
    • gt; Unpin.
  • Right click on the desktop: search, terminal, New (folder, text document, Word document), window layout, light or dark mode, personalization, displays.
  • Power card (Ctrl+Alt+Delete): lock, log out, restart, shut down.
  • Settings (start button > Settings): network, Bluetooth, appearance (colours, wallpaper, taskbar position), sound, displays, updates, programs, accounts.
  • Files on the desktop are the files in your Desktop folder. The thin strip at the right end of the taskbar shows the desktop.

Adding programs

  • Settings > Software > Apps installs a program from a package file (GoboLinux's own format, a file named like Name--Version--x86_64.tar.bz2), from a folder, a USB stick or an FTP server. The page checks the package first and says if it does not fit this system. Programs installed there can be removed on the same page.
  • Programs added this way open their files by double click when nothing else was chosen for that kind of file.
  • Advanced: GoboLinux's own tools (Compile, InstallPackage) work in a terminal as an administrator. Every program lives in its own folder under /Programs. A text file on this computer has more on this: /Programs/GoboSpin/Current/share/doc/software-install.txt.

Updates and going back

  • GoboRefined keeps two copies of the system (slots A and B). An update is installed into the copy that is not running and is used from the next restart. Your files and settings are on a separate data partition and are kept.
  • Install an update: Settings > Software > Updates > Install update from file..., or in a terminal sudo gobo-update /path/to/GoboRefined-<version>.update, then restart. Only update files signed by the GoboRefined project are accepted.
  • Go back to the previous version: the same page, or sudo gobo-update --rollback, then restart. If an updated system does not start, the computer goes back to the other copy by itself.
  • sudo gobo-update --status shows both copies and which one starts next.

Where settings are kept

~/.config/goborefined/Your GoboRefined choices: wallpaper, taskbar position, Settings look, your hotkeys (hotkeys), start menu pins and frequently used programs (start-pins, app-usage). Kept across updates.
~/.config/awesome/The desktop (Awesome): its configuration file rc.lua and the light/dark choice (mode). A system update puts the default files back, except the light/dark choice. Settings > Config edits and restores rc.lua (advanced).
~/.config/Settings of the other programs (file manager, clipboard history, default programs in mimeapps.list, ...).
/System/SettingsSystem-wide settings (administrators only). Changes there are kept across updates; sudo gobo-update --reset-system-changes undoes all of them.
/ProgramsEvery program in its own folder and version (the GoboLinux way).

Help and more

  • Something does not work: Settings > About > Save system report (or gobo-report in a terminal) writes one text file in your home folder that helps to find the cause.
  • GoboLinux documentation (online): gobolinux.org/documentation.html and the GoboLinux home page.
  • Awesome, the window manager behind the desktop: awesomewm.org/apidoc.

Window manager reference: open a terminal and type pinfo awesome (or Settings > Manual > Window manager reference).
